# C++ Expense Tracker

## About the Project

A simple menu-driven Expense Tracker developed using C++. It helps users record and manage their daily expenses through a command-line interface.

## Features

- Add new expenses
- Display all recorded expenses
- Calculate total expenses by category
- Calculate overall expenses
- Validate user inputs
- Handle invalid menu choices

## Technologies Used

- C++
- Standard Template Library (STL)
- VS Code
- MinGW GCC Compiler

## How to Run

1. Compile the program:

   `g++ main.cpp -o expense`

2. Run the program:

   `.\expense.exe`
